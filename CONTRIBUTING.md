## Guidelines for Copies, Forks & Contributions

1. **Attribution Requirement**:
   - Any copy, fork, or derivative work of this repository must retain original copyright notices and credit **Jarif Ovi** (`@jarifovi`) as the primary author in `LICENSE` and `README.md`.
2. **Submitting Pull Requests**:
   - Fork the official repository at [https://github.com/jarifovi/Real-Time-Chat-App](https://github.com/jarifovi/Real-Time-Chat-App).
   - Create a feature branch (`git checkout -b feature/AmazingFeature`).
   - Commit your changes with clear messages.
   - Push to your branch and open a Pull Request targeting `jarifovi/Real-Time-Chat-App:main`.

Thank you for building together! 🚀
